# 用語集

勘合の説明に出てくる言葉です。

## 勘合の言葉

- **勘合（かんごう）**：割符を合わせて、本物の使いかどうかを確かめること。室町時代の日明貿易で、正式な貿易船の証として使われた札の照合から名前を取りました。
- **割符（わりふ）**：二つに分けて、それぞれが持つ札。合わせてぴったり合えば本物と分かります。勘合では「あなたの契約台帳」と「会社の公式の住所」の2つが割符です。
- **契約台帳（台帳）**：あなたが取引している会社の一覧。端末の中に置きます。
- **名乗った会社**：文面の中に、その会社の名前（`words`）が出てくる会社。
- **公式の住所**：会社が自分で使っている、本物のドメイン。会社自身のページで確かめたものだけを一覧に入れます。
- **青・黄・赤**：判定の色。青＝割符が合った、黄＝確かめきれない、赤＝割符が合わない（偽物の疑いが強い）。
- **理由のコード**：判定の理由を表す短い英語の名前（`in_ledger`・`mimic` など）。一覧は [SPEC.md](../SPEC.md)。

## 住所（URL・ドメイン）の言葉

- **URL**：リンクの文字の並び全体。例：`https://www.rakuten-card.co.jp/e-navi/`
- **スキーム**：URL の頭の `https:` の部分。これが無くても、メッセージアプリは `example.com` のような文字をリンクにすることがあります。
- **ドメイン・ホスト名**：URL の中の「住所」の部分。例：`www.rakuten-card.co.jp`。勘合はここを照らし合わせます。
- **下の住所（サブドメイン）**：ドメインの前に `.` でつないだ住所。`www.rakuten-card.co.jp` は `rakuten-card.co.jp` の下の住所です。下の住所は、その会社しか作れません。
- **本物の住所の後ろに続けた住所**：`www.rakuten-card.co.jp.evil.example` のように、本物の住所を前に置き、後ろに別の住所を続けたもの。本当の持ち主は、いちばん後ろの `evil.example` の持ち主です。
- **利用者名（@ の前）**：URL の中で `@` より前に書かれた部分。住所ではありません。`https://本物の住所@偽の住所/` は、偽の住所が開きます。
- **ポート番号**：住所の後ろの `:443` のような番号。住所ではありません。
- **短縮 URL**：`bit.ly` などで短くしたリンク。行き先が見えません。
- **国際化ドメイン**：日本語や、ほかの国の文字を使った住所。ラテン文字そっくりの別の文字（キリル文字の「а」など）で、見た目だけ本物に似せることができます。中身は `xn--` で始まる形（Punycode）で表されます。
- **タイポスクワッティング**：本物によく似たつづりの住所（`rakut3n` など）を取る手口。
- **オープンリダイレクト**：本物のサイトの中にある、別のサイトへ転送する仕組みを悪用する手口。リンクの住所は本物なので、行き先が隠されていると勘合では見抜けません（行き先がリンクの中にそのまま書かれていれば、その住所も照らし合わせます）。

## 手口の言葉

- **フィッシング**：本物の会社や機関を装った連絡で偽サイトへ誘い、パスワードやカード番号を入力させる詐欺。
- **スミッシング**：SMS（ショートメッセージ）を使ったフィッシング。
- **ボイスフィッシング**：電話の声を使った詐欺。勘合では扱えません。
- **プロンプトインジェクション**：AI が読む文章の中に指示を紛れ込ませ、AI の動きをゆがめる手口。勘合が判定に AI を使わない理由の一つです。

## 仕組みの言葉

- **許可リスト・ブロックリスト**：許可リストは「本物の一覧」、ブロックリストは「危ないものの一覧」。勘合は許可リストで照らし合わせます。ブロックリストに代わるものではなく、組み合わせて使います。
- **決定的**：同じ入力には、いつでも同じ答えを返すこと。
- **共通の見本**：文面と、勘合が返すべき答えの組（`conformance/cases.json`）。Python と Swift のテストが両方とも読み込みます。勘合を別の言語に移す時は、これをすべて通します。
- **正規化（NFKC）**：全角の `ＡＭＡＺＯＮ` を `AMAZON` にするなど、見た目が同じ文字を同じ文字にそろえること。
- **正規表現**：文字の並びの「型」を書く書き方。勘合はリンクや電話番号を正規表現で見つけます。
- **パスキー**：パスワードの代わりに、端末で本人を確かめる仕組み（FIDO2 / WebAuthn）。登録した本物の住所でしか使えないので、偽サイトに入力してしまう事故を防げます。
