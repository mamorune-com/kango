# 守れる範囲

勘合が、どの手口にどう答えるか。そして、どこから先は守れないか。

## 前提

攻撃する側は、次のことができると考えています。

- どんな文章でも書ける（AI を使って、自然な日本語で）。
- どんな住所（ドメイン）でも取れる。会社名を入れた住所、見た目が似た文字の住所、本物の住所の後ろに続けた住所も取れる。
- 送り主の名前を偽れる（SMS の送信者名、メールの差出人名）。
- 短縮 URL・電話番号・返信先のメールアドレス・LINE の ID を使える。

勘合が頼りにしているのは、攻撃する側にできない次の2つです。

- **会社の本物の住所を取ること。**
- **あなたの端末の中の台帳を書き換えること。**

会社の本物の住所そのものが悪用された時は、勘合では守れません（下の「守れないこと」）。

## 手口と勘合の答え

台帳に「Amazon・楽天・ドコモ・ゆうちょ銀行」を入れた時の、勘合の実際の答えです。

**この表は、テストが毎回読み込んで、勘合を動かして確かめています**（`python/tests/test_docs.py` と `swift/Tests/KangoTests/DocsTests.swift`）。表に書いた答えと勘合の答えが食い違うと、CI が落ちます。表を足す時も、勘合を動かした結果をそのまま書いてください。

## 守れないこと

### 表で確かめている、誤った答え

| 手口 | 文面の例 | 答え | 理由のコード |
|---|---|---|---|
| 公式の住所の中にある転送ページを使い、行き先を `%` の書き方で隠す（誤った青。架空の例で、楽天カードにこのページがあるという意味ではありません） | `【楽天カード】ご確認 https://www.rakuten-card.co.jp/redirect?to=https%3A%2F%2Fevil.example%2F` | 青 | `in_ledger` `official` |
| メールアドレスへの返信を求める（誤った青） | `【楽天カード】ご本人様確認のため、rakuten-help@mail.example へご返信ください` | 青 | `in_ledger` |
| LINE の ID を友だち追加させる（誤った青） | `【楽天カード】お問い合わせはLINEで「rakuten-help」を友だち追加してください` | 青 | `in_ledger` |
| 本物の連絡に、別の会社名が出てくる（誤った赤。Apple も名乗ったとみなす） | `【楽天カード】Apple Pay に登録すると便利です https://www.rakuten-card.co.jp/` | 赤 | `in_ledger` `not_in_ledger` `official` |
| 使っている会社を台帳に入れ忘れた（誤った赤） | `【三井住友カード】ご利用明細のお知らせ https://www.smbc-card.com/` | 赤 | `not_in_ledger` `official` |
| 一覧にない会社（見分けられない） | `【〇〇信用金庫】口座の確認をお願いします https://shinkin-check.example/` | 黄 | `no_claim` `unknown_domain` |
| リンクの直後に日本語が続く（誤った赤。住所に日本語が混ざったとみなす） | `【楽天カード】詳しくは https://www.rakuten-card.co.jpをご覧ください` | 赤 | `in_ledger` `idn` |
| 本物の会社からの、顔認証の作り直しのお願い（青にしない。公式アプリから自分で操作する方が安全なので、黄にしている） | `【ドコモ】顔認証の再設定をお願いします https://www.docomo.ne.jp/` | 黄 | `in_ledger` `official` `takeover` |

誤った青は、勘合がいちばん避けたいものです。上の3つは、勘合が照らし合わせていないもの（公式の住所の中での転送・メールアドレス・LINE の ID）が使われた例です。名乗った会社が台帳にあっても、**返信・友だち追加・電話・アプリの入れ直しなどを求められたら、連絡の中の案内は使わず、自分で確かめた窓口から確かめてください。**

### 勘合が扱わないもの

- **会社のアカウントやサイトそのものの乗っ取り。** 本物の住所から偽の連絡が来たら、青になりえます。
- **誰でも使える公式の仕組みの悪用。** 共有リンク・送金の依頼・ブログ・問い合わせフォームなど、本物の住所の上に誰でも中身を置ける仕組みは、青になりえます。
- **画像の中の文字・QR コード・添付ファイル。** 勘合が受け取るのは文字だけです。呼び出す側で文字にしてから渡せば照らし合わせられます。
- **電話の声・対面・郵便。** 声で名乗る詐欺（ボイスフィッシング）は扱えません。
- **端末やアカウントの乗っ取り、ウイルス、人の手によるハッキング、内部の人による持ち出し、うっかりミス、災害。** 勘合は「届いた連絡を照らし合わせる」だけの部品です。

## 組み合わせて使うもの

勘合は守りの一部です。次のものと一緒に使ってください。

- OS とアプリを最新にする。
- パスキーや2段階認証を使う。パスキーは登録した本物の住所でしか使えないので、偽サイトに入力してしまう事故そのものを防げます。
- 携帯会社やメールの迷惑メッセージのフィルター、ブラウザの危険なサイトの警告（危ない住所の一覧）を有効にしておく。
- リンクからではなく、公式アプリやいつものブックマークから開く習慣。
- 迷ったら相談する：警察相談専用電話（#9110）、消費者ホットライン（188）。

## これから検討していること

約束ではありません。誤った赤を増やさずにできるかを確かめてから、規則にします。

- リンクの中に、`%` の書き方で隠した別のリンクが入っている時（転送）に、その行き先も照らし合わせる（そのまま書かれた行き先は、v0.6.2 から照らし合わせています）。
- メールアドレスの住所（`@` の後ろ）も、公式の住所と照らし合わせる。
- 「名乗った会社」を、文面の頭の【】や署名から読むようにして、別の会社名がただ出てくるだけの誤った赤を減らす。
